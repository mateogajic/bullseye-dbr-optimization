# Post-processing of RSoft extraction-efficiency sweeps

MATLAB scripts for calculating the extraction efficiency from spatial
power-monitor files exported by RSoft. The scripts were developed for the
numerical optimization of Bullseye structures with and without a distributed
Bragg reflector (DBR).

## Scripts

- `scripts/single_parameter_sweep.m` processes simulations in which one
  parameter is varied. It plots the extraction efficiency, identifies the
  optimum and exports the numerical results and figure.
- `scripts/double_parameter_sweep.m` processes simulations in which two
  parameters are varied simultaneously. It creates an efficiency map,
  identifies the joint optimum and exports the map and numerical results.

## Extraction-efficiency calculation

For every simulation, the scripts read the normal power density on a
two-dimensional spatial monitor. The extraction efficiency is approximated by

$$
\eta_{\mathrm{ext}} \approx
f_{\mathrm{sym}}\sum_{i,j}P_{ij}M_{ij}\,\Delta x\,\Delta y,
$$

where $P_{ij}$ is the power density at each monitor point, $M_{ij}$ is a
circular mask, $f_{\mathrm{sym}}$ is the symmetry factor, and $\Delta x$ and
$\Delta y$ are the grid spacings. The result is a power fraction when the RSoft
simulation is normalized to unit launched power.

## Requirements

- MATLAB R2020a or later.
- Spatial power-monitor files generated by RSoft.
- No additional MATLAB toolboxes are required.

## Data layout

Raw simulation data are not included in this repository. Place them under the
local `data/` directory using the structure configured at the beginning of each
script.

The single-parameter script expects filenames of the form

```text
<tag>_<index>_<monitor>_<frequency>_pow.dat
```

inside

```text
data/<simulation_folder>/<tag>_work/
```

The double-parameter script expects filenames of the form

```text
<tag>_<index_parameter_1>_<index_parameter_2>_<monitor>_<frequency>_pow.dat
```

inside

```text
data/<simulation_folder>/
```

For a double sweep, the order of the two filename indices must match the order
of the parameters in the RSoft MOST sweep.

## Usage

1. Place the RSoft output files under `data/`.
2. Edit the configuration section at the beginning of the relevant script.
3. Run the script in MATLAB.
4. Enter the symmetry factor for the simulated domain:
   - `1` for the complete structure;
   - `2` for half of the structure;
   - `4` for one quarter;
   - `8` for one octant.
5. Find the generated CSV, MATLAB figure and vector PDF under `results/`.

The monitor reader validates the grid dimensions against the file metadata.
Missing, truncated or malformed files are reported and excluded rather than
being silently padded or truncated.
